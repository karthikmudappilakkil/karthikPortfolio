# Karthik M P — Developer Portfolio

A personal developer portfolio built with **React, TypeScript, and Vite**. The site presents selected projects, technical skills, professional experience, education, and contact information in a bold editorial poster-inspired design.

## Portfolio Sections

- **Hero:** Introduction and developer profile.
- **About:** Personal and professional overview.
- **Technical skills:** Languages, frontend and mobile technologies, backend tools, databases, and development ecosystem.
- **Selected projects:** Project cards with descriptions, technology tags, highlights, and links to live websites where available.
- **Experience and education:** Professional experience, training, and academic background.
- **Contact:** Ways to get in touch.

## Featured Work

The portfolio currently highlights:

- **Minler Jewels:** Custom Shopify silver jewellery storefront.
- **Aeriz Way Logistics:** Corporate freight and cargo website.
- **Women's Safety & Health Platform:** Academic web and mobile application project.

## Run Locally

### Prerequisites

- Node.js
- npm

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/karthikmudappilakkil/karthikPortfolio.git
   cd karthikPortfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal.

### Production Build

Run the TypeScript check and create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
